## ✨ About

**Movie Library** is a clean and modern movie management app designed to make it easy to browse, organize, and keep track of your movie collection.

The project focuses on a smooth interface, simple navigation, and a pleasant viewing experience.

## 🚀 Features

#- 🎞️ Add Videos from any of links/ftp/databases/storage servers etc & custom links attachable with many more...
#- 🌐 Inbuilt browser with advanced tools & Fetching automatically video links and adding to library with title, Arts/Covers, subtitles etc.
#- 🎞️ Browse movie collection
#- 🔎 Search movies
#- ⭐ Favorites
#- 📚 Movie categories
#- 🎬 Movie details
#- 🖼️ Movie posters & artwork
#- 📱 Modern responsive UI
#- 🌙 Clean dark-themed interface
#- ⚡ Smooth navigation and interactions
